# Segurança

O Sonyia processa mídia localmente e não possui backend. A política completa de segurança, incluindo controles, limites e riscos residuais, está em [docs/SECURITY.md](docs/SECURITY.md).

Para privacidade, veja [docs/PRIVACY.md](docs/PRIVACY.md).

## Reportar vulnerabilidades

**Não abra uma issue pública com detalhes exploráveis.** Envie o relato ao mantenedor Victor de Brito Brandão pelos canais privados de segurança do repositório do GitHub (Security → Report a vulnerability), ou por contato direto combinado com o mantenedor.

Inclua versão afetada, navegador/sistema, passos de reprodução, impacto e, se possível, uma prova de conceito mínima. Você receberá uma confirmação e, quando aplicável, a correção será documentada no [CHANGELOG.md](CHANGELOG.md). Não há afirmação de risco zero.
